# КРУГ MVP

Запуск:

```bash
python3 -m http.server 4173
```

Открыть: http://localhost:4173

Одностраничный кликабельный MVP-прототип веб+мобайл интерфейса КРУГ с тёмной темой, регистрацией, пустыми состояниями, созданием круга/поста, профилем, редактированием данных, локальной базой пользователей и поиском по никам (LocalStorage).
